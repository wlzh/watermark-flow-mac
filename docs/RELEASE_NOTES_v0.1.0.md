# WatermarkFlow v0.1.0

WatermarkFlow 首个可用版本，提供原生 macOS 菜单栏图片水印工作流。

## 主要功能

- 从剪贴板、文件或拖放载入图片，并在当前会话中保留原图进行非破坏式编辑。
- 支持文字、X、YouTube 和自定义 Logo 水印。
- 提供 `X · @wlzh`、`X · @gxjdian` 和 `YouTube · 短裤AI分享` 三套内置模板。
- 支持位置、前景色、背景色、图标色、透明度、大小和旋转设置。
- 可生成并复制到剪贴板，或导出 PNG/JPEG。
- 提供默认 `⌥⌘W` 全局快捷键和菜单栏快速处理。
