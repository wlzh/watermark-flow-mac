# WatermarkFlow 0.3.0

本版本增加一键满屏水印和可调密度。

## 变化

- 每个模板可在“单个”和“满屏”水印之间一键切换。
- 满屏模式以错列网格重复当前文字、Logo或组合水印。
- 平铺密度支持 1–10 级，继续复用颜色、透明度、大小和旋转设置。
- 布局和密度自动保存，默认模板与菜单栏快速生成同样适用。
- 满屏模式不改变单水印位置，切回后恢复上次拖动坐标。
- 旧模板自动迁移，原有模板默认保持单水印效果。

## 安装提示

当前二进制为 Universal `arm64 + x86_64`、MIT License、ad-hoc 签名且尚未 notarize。首次启动若被 Gatekeeper 拦截，请在 Finder 中按住 Control 点击应用并选择“打开”。
