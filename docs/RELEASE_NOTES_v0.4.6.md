# WatermarkFlow v0.4.6

本版本修复微信复制图片后快速生成“间歇性失败、弹出主窗口且无解释”的问题。

## 主要变化

- 微信等应用复制图片时附带的临时文件被系统清理后，快速生成自动回落读取剪贴板原生图片数据，继续正常输出水印图。
- 快速生成失败时在主窗口弹出明确的原因说明和补救建议，不再只有右上角一行小字。
- 失效文件且无原生数据时的报错改为“复制的图片文件已失效，请重新复制图片”。
- 系统“从其他 App 粘贴”权限被拒绝时，提示指向 系统设置 › 隐私与安全性。
- 快速生成链路新增统一日志，可在“日志”App 中按 `com.wlzh.WatermarkFlow` 过滤排查。
- 上一次快速生成处理中再次触发时给出状态提示，不再静默忽略。

## 兼容性

- 多文件剪贴板仍拒绝隐式选择，HTML 单图回退、大小上限、输出像素与模板策略不变。
- 模板 schema 保持 4，无模板数据迁移。
- 支持 macOS 13 及以上的 Apple Silicon 与 Intel Mac。

## 安装提示

当前安装包为 ad-hoc 签名且未经过 Apple notarization。首次打开时如被系统拦截，请在 Finder 中按住 Control 点击应用并选择“打开”。
