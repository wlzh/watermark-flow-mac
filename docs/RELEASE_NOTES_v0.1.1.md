# WatermarkFlow v0.1.1

本版本完善模板参数和最后选择状态的持久化。

## 变化

- 自动保存文字、Logo、颜色、透明度、大小、位置和旋转角度。
- 重启应用或处理下一张图片时恢复最后选择的模板和已保存参数。
- 内置模板允许保存用户覆盖，同时保持不可删除和出厂默认回退能力。
- 模板存储引入版本化结构，并兼容迁移 v0.1.0 数组格式。
- 发布自检改用隔离 pasteboard，避免修改用户通用剪贴板内容。

## 分发说明

该版本使用本机 ad-hoc 签名。版本代码保留于 Git 标签 `v0.1.1`，未在 GitHub Releases 保留安装资产。
