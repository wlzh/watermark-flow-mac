# WatermarkFlow v0.3.2

本版本修复新增自定义 Logo + 文字模板流程不清楚、容易修改原模板或留下未启用 Logo 的问题。

## 变化

- 新增“新建 Logo + 文字模板”，先创建独立模板再编辑，不修改来源模板。
- 自定义 Logo 可以与文字组合，界面会显示尚未选择、已嵌入及文件大小。
- 模板中已有 Logo 但当前选择了其他图标时，会提示 Logo 没有显示并可一键重新启用。
- “另存模板”改为“复制当前模板”，完整复制 Logo、文字和单个/满屏两套设置。
- Logo 读取或处理失败时显示明确错误。
- 增加真实 PNG、保存、重启、复制及快速渲染完整回归测试。

## 安装提示

当前二进制为 Universal `arm64 + x86_64`、MIT License、ad-hoc 签名且尚未 notarize。首次启动若被 Gatekeeper 拦截，请在 Finder 中按住 Control 点击应用并选择“打开”。
