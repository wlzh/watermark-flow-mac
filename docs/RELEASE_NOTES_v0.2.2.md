# WatermarkFlow 0.2.2

本版本增加当前会话水印的移除、恢复和替换能力。

## 变化

- 在画布右键菜单、模板区、底部工具栏和应用菜单中移除当前水印。
- 移除后保留原图和全部模板参数，可随时重新添加所选水印。
- 选择其他模板会直接替换当前水印，不会叠加多个水印。
- 无水印状态下复制或导出得到原图；载入下一张图片时恢复所选模板。
- 大图支持 25% 至 1000% 缩放、百分比选择和滚动查看，100% 为适合窗口。
- “显示”菜单提供 `⌘+`、`⌘-`、`⌘0` 快捷操作。
- 增加 source-only 输出、移除恢复、模板替换和菜单状态测试。

## 安装提示

当前二进制为 Universal `arm64 + x86_64`、ad-hoc 签名且尚未 notarize。首次启动若被 Gatekeeper 拦截，请在 Finder 中按住 Control 点击应用并选择“打开”。
