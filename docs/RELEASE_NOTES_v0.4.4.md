# WatermarkFlow v0.4.4

本版本增加 Finder 图片文件剪贴板支持。复制图片文件后，可以像直接复制图片内容一样自动载入、编辑或使用快捷键生成水印。

## 主要变化

- 支持剪贴板中的单个本地图片文件。
- 空画布自动载入、主窗口“从剪贴板载入”、全局快捷键和菜单栏模板快速生成全部生效。
- 主窗口按钮与快捷处理改为使用同一套完整解析能力。
- 多个文件不会被擅自选择；主动操作时会提示只复制一个图片文件。
- 文件夹、非图片文件和超过 512 MB 的文件不处理。

## 隐私与兼容性

- 本地图片文件只读解码，不修改源文件，也不发起网络请求。
- HTML 网页图片仍只在用户主动操作时从单个 HTTPS 原地址读取。
- 模板 schema 保持 4，已有模板、颜色、位置、布局、快捷默认模板和快捷键无需迁移。
- 支持 macOS 13 及以上的 Apple Silicon 与 Intel Mac。

## 安装提示

当前安装包为 ad-hoc 签名且未经过 Apple notarization。首次打开时如被系统拦截，请在 Finder 中按住 Control 点击应用并选择“打开”。
