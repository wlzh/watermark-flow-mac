# WatermarkFlow 0.2.0

本版本完善多模板快捷工作流、可配置全局快捷键、画布清空、深浅色界面和大图预览性能。

## 主要变化

- 菜单栏可选择任意已保存模板快速生成并复制，默认模板带勾选。
- 全局快捷键可录制、自动保存和恢复默认 `⌥⌘W`。
- 当前图片可从画布右键或底部按钮清空，模板及最后拖动位置保留。
- 深色模式使用低眩光暖灰文字，浅色模式保持纸张风格。
- 预览最长边限制为 1200 像素，最终输出保持原始像素。
- 发布包同时支持 Apple Silicon 和 Intel Mac。

## 安装提示

当前二进制使用 ad-hoc 签名，尚未进行 Apple Developer ID 签名和 notarization。首次启动若被 Gatekeeper 拦截，请在 Finder 中按住 Control 点击应用并选择“打开”。压缩包完整性可使用随附的 `SHA256.txt` 验证。
