# WatermarkFlow v0.4.3

本版本修复飞书等网页应用中复制图片后，快捷键弹出主窗口但没有生成水印的问题。

## 主要变化

- 原生 PNG/TIFF 继续直接处理。
- 剪贴板只有一张 HTML 网页图片时，快捷键会从图片原 HTTPS 地址读取并继续生成水印。
- “从剪贴板载入”获得相同的网页单图兼容能力。
- 网页图片读取和渲染异步执行，连续按快捷键不会重复启动任务。
- 多图、不安全地址、下载失败和超过 64 MB 的图片会给出明确提示。
- 菜单栏新增“设置快捷默认模板”，无需打开主窗口即可切换以后快捷键使用的模板；原有“选择模板快速生成并复制”继续用于临时处理一次。

## 隐私与兼容性

- 后台剪贴板自动发现不会发起网络请求。
- 网页图片仅在用户主动操作后从原地址读取；水印渲染仍完全在本机完成，不上传原图或结果。
- 模板 schema 保持 4，已有模板、位置、颜色和快捷设置不迁移。
- 支持 macOS 13 及以上的 Apple Silicon 与 Intel Mac。

## 安装提示

当前安装包为 ad-hoc 签名且未经过 Apple notarization。首次打开时如被系统拦截，请在 Finder 中右键应用并选择“打开”。
