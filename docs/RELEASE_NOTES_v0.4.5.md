# WatermarkFlow v0.4.5

本版本修复复制图片后按默认快捷键偶尔没有生成水印的问题。

## 主要变化

- 默认快捷键由 `⌥⌘W` 改为 `⌃⌥⌘W`。
- 新组合避开 macOS 标准的“关闭全部窗口”命令，降低微信等前台应用截获按键的可能。
- 旧默认值会在启动时自动迁移并保存，不需要手动设置。
- 用户自行录制的其他快捷键保持不变。
- 恢复默认按钮、菜单栏命令和使用说明全部显示实际新组合。

## 兼容性

- 图片来源、模板、位置、颜色、单个/满屏配置、快捷默认模板和剪贴板策略不变。
- 模板 schema 保持 4，无模板数据迁移。
- 支持 macOS 13 及以上的 Apple Silicon 与 Intel Mac。

## 安装提示

当前安装包为 ad-hoc 签名且未经过 Apple notarization。首次打开时如被系统拦截，请在 Finder 中按住 Control 点击应用并选择“打开”。
