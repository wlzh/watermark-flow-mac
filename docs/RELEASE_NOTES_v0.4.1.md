# WatermarkFlow v0.4.1

本版本为画布操作增强版本。

## 新功能

- 指针位于画布内时，标准鼠标滚轮可在 25% 至 1000% 之间逐级缩放图片。
- 放大后可按住图片非水印区域拖动查看，图片和水印同步移动且水印坐标不变；直接拖动水印仍用于定位。
- 精细触控板滚动继续用于平移放大后的画布，横向滚动不会误触发缩放。
- 画布帮助和底部状态增加滚轮操作提示。

## 兼容性与数据

- 模板 schema 保持 4，升级不会迁移或修改已有模板。
- 缩放只影响预览，不改变原图、水印参数、输出分辨率或模板保存结果。
- 支持 macOS 13 及以上的 Apple Silicon 与 Intel Mac。

## 安装提示

当前安装包为 ad-hoc 签名且未经过 Apple notarization。首次打开时如被系统拦截，请在 Finder 中右键应用并选择“打开”。
