# WatermarkFlow v0.4.6 测试报告

## 范围

- 版本：`0.4.6 (17)`
- 日期：2026-11-06
- 平台：macOS 27.2，Apple Silicon 主机
- 模板 schema：`4`

## 问题证据

- 现场安装版本与仓库 dist 构建哈希一致（v0.4.5 build 16），排除版本漂移。
- 失败时主窗口弹出只可能来自 `performQuickApply` 的异常分支；失败原因仅写入主窗口右上角 11pt 状态小字，用户不可感知。
- v0.4.5 测试报告记录过微信复制图片在剪贴板放置临时目录文件 URL 的现场；微信会清理临时目录，文件消失后 `NSImage(contentsOf:)` 必然失败，且原实现不会回落读取剪贴板可能同时携带的原生像素数据。
- macOS 15.4 起引入剪贴板隐私机制，本机探针显示通用剪贴板对常规读取为 `alwaysAllow`，未拦截；仍为拒绝状态的用户新增专属提示。
