## 界面复验

- 实际启动 `/Applications/WatermarkFlow.app`，确认版本 `0.3.2 (10)` 且进程正常。
- 主窗口显示“＋ 新建 Logo + 文字模板”“图标类型”和“复制当前模板”，右侧检查器无重叠或截断。
- 使用真实现有配置验证：模板内存在 Logo 数据但当前图标类型为 YouTube 时，正确显示“已嵌入的自定义 Logo 当前未显示”和“启用 Logo”。
- 新建、导入、输入文字、保存、重启、复制和快速渲染操作由隔离应用数据的应用自检逐项执行，避免污染用户模板。
