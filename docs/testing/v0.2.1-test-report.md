## 性能

本机 4000×3000 调试基准：1200×900 预览约 `19.0 ms`，4000×3000 最终渲染约 `6.9 ms`。数值受即时负载影响，仅用于量级判断。预览持续持有的 RGBA 像素由约 48 MB 降至约 4.3 MB；最终渲染不降采样。超大 Logo 规范化后最多持有 1024 像素长边，避免数千万像素 Logo 反复参与模板序列化和预览解码。
