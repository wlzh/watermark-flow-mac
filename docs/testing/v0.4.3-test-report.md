## 复现证据

- 失败现场剪贴板版本：`95`。
- 类型只有 HTML、纯文本和 Chromium 来源字段，没有 PNG/TIFF。
- `canReadObject(NSImage.self)` 与 `NSImage(pasteboard:)` 均失败，应用显示“剪贴板中没有可读取的图片”。
- HTML 恰好包含一张飞书图片，准确 `src` 可读取为 1254×768 PNG；`data-src` 需要鉴权并返回 401，因此解析必须优先准确属性名 `src`。

## 真实场景复验

- 剪贴板版本 113–115 均只有飞书 HTML、纯文本和 Chromium 来源字段，无法直接解码为图片。
- 按一次 `⌥⌘W` 后，剪贴板版本 116 变为 PNG/TIFF，尺寸 1122×561。
- 应用状态为“已用‘YouTube · 短裤AI分享’快速生成并复制”，没有产生新的失败提示。
- 输出 PNG 为 91,134 字节，SHA-256 为 `f518d20df480e84612b9852208e6242bee6bacc1b29a91b301dd8cb2f9e893f9`；视觉检查确认水印正确叠加。
- “关于”窗口显示 `0.4.3 (14)` 及“图片仅在本机处理；网页图片仅从原地址读取”。
