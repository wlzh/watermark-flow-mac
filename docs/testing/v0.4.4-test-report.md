## 本机真实流程

- 使用 1024×1024 PNG 文件向系统通用剪贴板写入 Finder 同型 `public.file-url`，确认仅包含一个本地文件 URL。
- 已安装应用启动后自动载入为 1024×1024，证明生产二进制的后台观察路径能识别文件型剪贴板。
- 再次写入同一文件 URL 并按 `⌥⌘W`，剪贴板变为 PNG/TIFF，输出仍为 1024×1024。
- 输出 PNG 为 498,955 字节，SHA-256 为 `17875678f222cf7d8b2cb1d041141399021f2d2fc863364e03e379ced99b399d`；视觉检查确认右下角叠加 `YouTube · 短裤AI分享`。
- Finder UI 自动化会在“拷贝”后恢复先前剪贴板内容，因此现场验证改为直接写入完全相同的系统文件 URL 表示；核心测试另以隔离剪贴板真实文件对象覆盖该来源。
