## 性能

| 场景 | 调试构建实测 |
| --- | --- |
| 4000 × 3000 预览 | 约 18.2 ms，输出 1200 × 900 |
| 4000 × 3000 单水印输出 | 约 6.3 ms，输出 4000 × 3000 |

## 一致性审计

- 主窗口、菜单栏、README、安装说明和发布说明统一使用“快捷默认模板”。
- 剪贴板默认策略、覆盖规则、忽略规则和自身输出抑制的代码、界面与文档一致。
- 自动对比属于当前模板当前布局；关闭不修改手动颜色，代码、界面与迁移规则一致。
- 位置仅单个模式使用，密度仅满屏模式使用；其余视觉设置及自动对比为两套独立配置。
- 作者、作者链接、网站、MIT License、版本号和构建号由构建门禁统一检查。
