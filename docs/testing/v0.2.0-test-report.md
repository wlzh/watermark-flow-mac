## 性能检查

调试构建的一次 4000 × 3000 基准：1200 像素预览约 `18.6 ms`，全分辨率最终渲染约 `6.3 ms`。数值受机器负载影响，仅作量级参考。预览路径的主要收益是把持续持有的合成预览从约 48 MB RGBA 像素降至约 4.3 MB，减少大图编辑时的内存压力；最终输出不降采样。
