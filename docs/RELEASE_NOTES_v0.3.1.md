# WatermarkFlow v0.3.1

本版本修正单个水印与满屏水印共用调节参数的问题。

## 变化

- 每个模板分别保存“单个样式”和“满屏样式”。
- 两套样式的文字色、背景色、图标色、透明度、大小和旋转完全独立。
- 单个模式继续保存自己的位置，满屏模式继续保存自己的 1–10 级密度。
- 切换布局时立即恢复该布局上次使用的设置，重启和处理下一张图片后仍保留。
- 默认模板、菜单栏选择模板快速生成和主窗口输出都会使用所选模板当前布局的对应配置。
- 旧模板首次读取后自动迁移并原子写回；升级时原有视觉参数会复制为两套初始配置，不改变原有效果。

## 安装提示

当前二进制为 Universal `arm64 + x86_64`、MIT License、ad-hoc 签名且尚未 notarize。首次启动若被 Gatekeeper 拦截，请在 Finder 中按住 Control 点击应用并选择“打开”。
