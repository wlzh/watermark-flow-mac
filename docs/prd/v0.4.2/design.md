# WatermarkFlow v0.4.2 视觉设计

## App 图标

- 外形：符合 macOS 视觉习惯的圆角方形，保留透明外缘。
- 背景：深青绿到明亮水绿的对角渐变，与应用强调色一致。
- 主体：暖白图片卡片，包含金色光点和两层青绿色山景，第一眼先识别为图片。
- 水印：深色半透明斜向带覆盖图片中下部，使用暖白矢量 W 明确表达水印叠加。
- 细节：卡片阴影、外框高光和水印边线只增强层次，不承担核心识别。

## 菜单栏图标

- 使用 18×18 point 单色矢量模板图，而非缩小彩色 App 图标。
- 左上主体为圆角图片框、光点和山形；右下叠加带 W 的小徽标。
- 图标只提供 alpha 轮廓，由 macOS 根据普通、深色和菜单高亮状态自动着色。
- 无障碍名称为“WatermarkFlow 图片水印”。

## About 窗口

- 使用 90×90 point 的真实应用图标，保持高质量插值。
- 其余排版、链接、颜色和隐私说明不改变。
