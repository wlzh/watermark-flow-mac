# WatermarkFlow v0.4.6 交互设计

## 失败提示

- 菜单栏模板快速生成与全局快捷键失败时，主窗口置前并弹出警告框：标题“快速生成并复制失败”，正文为具体原因，必要时附“重新复制图片 / 网页图片右键复制图像”的补救建议。
- 同一时刻只保留一个警告框；连续失败只更新状态区文案，不叠加弹窗。
- 权限拒绝的提示不附加重试建议，只保留指向 系统设置 › 隐私与安全性 › 从其他 App 粘贴 的指引。
- 菜单栏图标沿用沙漏 / 勾选 / 感叹号三态反馈，失败时播放系统警告音。

## 处理中反馈

- 上一次快速生成未完成时再次点击菜单或快捷键，状态区提示“上一次快速生成仍在处理，请稍候”，不静默忽略。

## 行为保持

- 多文件剪贴板仍然拒绝隐式选择，避免给错误的图片加水印。
- HTML 单图回退、远程图上限、输出像素与写回剪贴板策略均不变。
