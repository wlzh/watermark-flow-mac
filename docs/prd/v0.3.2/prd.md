## 背景

新增 Logo 与文字组合模板时，原流程要求先编辑当前模板再“另存”。由于模板参数会自动保存，用户在创建副本前可能已经改变原模板；“品牌”和“自定义 Logo”的命名也没有明确说明图标类型互斥，容易形成 Logo 已保存但没有启用、文字为空的模板。

## 功能目标

- 提供独立的新建 Logo + 文字模板入口。
- 新建模板时不改变来源模板的内容、Logo、布局或样式。
- 新模板创建后立即成为当前模板，并进入自定义 Logo + 文字编辑状态。
- 明确展示 Logo 尚未选择或已嵌入状态。
- 当模板内已有 Logo 但当前使用 X、YouTube 或纯文字图标时，提示 Logo 未显示并允许一键启用。
- 复制现有模板时完整保留 Logo、文字、单个与满屏两套样式。
- 导入失败时给出明确错误，不静默忽略。

## 验收标准

1. 从任意模板新建 Logo + 文字模板后，原模板逐字段保持不变。
2. 导入真实 PNG、输入文字并保存后，重启仍恢复 Logo、文字、布局、位置、密度与两套样式。
3. 新模板可以在主窗口、菜单栏快速模板和全分辨率输出中正确渲染。
4. 复制自定义模板不会丢失 Logo 二进制、文字或样式。
5. 已有 Logo 但未启用时，界面提供明确提示和恢复按钮。
6. 自动化测试、应用自检、Universal 构建、签名、本机安装和 Release 校验通过。

## 非目标

- 不自动修改或删除用户已有模板。
- 不引入多个 Logo 图层或多文字图层。
- 不改变当前会话内非破坏式编辑边界。
