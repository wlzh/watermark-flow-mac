# WatermarkFlow v0.3.2 界面设计

## 模板区

模板选择器下方新增“＋ 新建 Logo + 文字模板”按钮。点击后输入模板名称；创建成功即选中新模板，避免用户在已有模板上先编辑。

## 内容区

- “品牌”标签改为“图标类型”。
- 选项“自定义 Logo”改为“自定义 Logo + 文字”。
- 未导入 Logo 时使用克制的警示色显示“尚未选择 Logo”。
- 已导入时显示“已嵌入”和文件大小，并将按钮改为“更换 Logo 图片…”。
- Logo 数据存在但图标类型不是自定义时，显示“已嵌入的自定义 Logo 当前未显示”和“启用 Logo”按钮。

## 模板管理区

“另存模板”改为“复制当前模板”，强调该操作复制当前全部设置。新建与复制成为两个边界清楚的操作：新建用于开始新的 Logo + 文字模板，复制用于克隆已有成品。

## 反馈

成功导入显示文件名；读取或规范化失败显示具体错误。所有新增文字沿用现有深浅色语义色板，警示色避免纯白高亮。
