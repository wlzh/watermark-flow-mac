## 背景

多模板工作流需要明确区分编辑器最后选择和全局快捷键默认模板。复制图片后手动载入步骤可以自动化，但不能覆盖正在编辑的图片，也不能把应用自己的输出再次当作输入。固定水印颜色在明暗变化大的图片上可读性不稳定，需要按水印实际区域适配，同时保留手动颜色和品牌 Logo 原色。

## 功能目标

- 从全部模板中直接选择快捷默认模板，并在菜单栏命令中显示具体名称。
- 快捷默认模板与编辑器最后选择分别保存，任一变化不改写另一项。
- 主窗口可自动发现系统剪贴板中的新图片。
- 剪贴板策略支持关闭、仅空画布自动载入、始终自动替换，默认使用安全的仅空画布模式。
- 已有图片时提供载入并替换或忽略操作，不静默覆盖。
- 忽略非图片内容，并抑制应用自身复制输出，避免循环叠加水印。
- 每个模板的单个与满屏样式分别保存自动对比模式和强度。
- 自动对比支持关闭、仅文字、文字 + 背景，以及柔和、标准、强烈三档。
- 单个水印分析其实际覆盖区域；满屏水印逐块分析各自区域。
- 自动结果只参与渲染，不覆盖模板保存的手动颜色。

## 一致性要求

- 旧模板升级后外观不变，自动对比默认关闭。
- 自定义 Logo 保持原色；YouTube 红色保持品牌色；X 图标可随自适应前景色变化。
- 当前会话仍保留原图和可编辑参数，复制和导出才生成扁平结果。
- 位置仅属于单个模式，密度仅属于满屏模式；颜色、透明度、大小、旋转、自动对比模式和强度均为两套独立配置。
- 菜单、主窗口、README、安装说明和发布说明使用统一术语“快捷默认模板”“自动对比”“剪贴板图片”。

## 验收标准

1. 任意内置或用户模板均可设为快捷默认，重启后恢复，编辑器最后选择不受影响。
2. 菜单栏快捷命令显示当前默认模板名称和快捷键；临时模板子菜单仍可选择其他模板。
3. 空画布复制图片后自动载入；已有画布时默认只提示，不覆盖。
4. 始终替换、关闭、待替换、忽略、非图片和应用自身写入六条剪贴板路径均有自动化验证。
5. 自动对比在黑、白、分区、透明、复杂和满屏图片上使用局部结果，输出尺寸保持原始像素。
6. 单个与满屏的自动对比参数互不覆盖，重启后完整恢复。
7. Logo + 文字模板、拖动、缩放、清空、移除、快捷键、编码、迁移等既有功能全部回归通过。
8. Universal 构建、签名、安装、界面复验、ZIP、SHA-256 和 GitHub Release 通过。

## 非目标

- 不保存上次编辑图片或跨重启恢复未导出的编辑会话。
- 不做物体识别、OCR 或语义避让。
- 不修改自定义 Logo 的内部像素颜色。
- 不引入多图层、批处理或云端服务。
