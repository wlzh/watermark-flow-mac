# WatermarkFlow v0.4.0 界面设计

## 模板与快捷默认

- 模板选择器在当前快捷默认项后显示“快捷默认”。
- 模板管理按钮在未选中默认模板时显示“设为快捷默认”，已选中时显示“已是快捷默认”并禁用重复操作。
- 快捷操作区提供“快捷默认模板”下拉框，不要求先切换当前编辑模板。
- 菜单栏命令显示“使用快捷默认模板：模板名 · 快捷键”，降低多模板误用风险。

## 剪贴板图片

- 快捷操作区提供关闭、仅空画布自动载入、始终自动替换三种策略。
- 默认“仅空画布自动载入”，避免覆盖正在编辑的图片。
- 检测到待替换图片时，在底部工具栏上方显示紧凑提示条，提供“忽略”和“载入并替换”。
- 忽略后，同一剪贴板版本不重复提示；新复制图片才再次触发。
- 状态栏区分自动载入、手动载入、检测到待替换和忽略结果。

## 自动对比

- 在当前“单个样式”或“满屏样式”区显示三段式自动对比选择。
- 启用后显示强度下拉框及说明“按水印所在区域自动适配；手动颜色仍保留，关闭后恢复”。
- 手动文字、背景和图标颜色控件始终可见，避免用户误以为原设置被删除。
- 单个/满屏切换沿用已有独立参数提示，自动对比也遵循同一隔离规则。

## 视觉与排版

- 继续使用深浅色语义色板，正文和辅助文字不使用刺眼纯白。
- 画布内的白色空状态文字仅用于深色画布背景，不用于右侧检查器。
- 新增控件放入可滚动检查器，窗口最小尺寸、底部工具栏和画布区域不被挤压。
