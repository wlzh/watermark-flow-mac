# WatermarkFlow v0.4.0 开发记录

## 数据模型与迁移

- 模板 schema 从 3 升级为 4。
- `WatermarkVisualSettings` 增加 `contrastMode` 与 `contrastStrength`，因此单个和满屏分别保存自动对比。
- 顶层单个样式也增加同名字段，并通过活动属性路由到当前布局。
- schema 3 及更早数据缺少字段时迁移为 `off` 和 `standard`，原有颜色和渲染结果不变。
- 剪贴板策略保存到 `UserDefaults`，默认 `emptyCanvas`。

## 自动对比算法

- 每次渲染最多建立一个最长边 128 像素的 sRGB 亮度图。
- 亮度使用 WCAG 线性化系数，并建立亮度与亮度平方积分图。
- 单个和每个平铺水印将旋转后的外接矩形映射到亮度图，区域均值和标准差以常数时间取得。
- 仅文字模式直接选择与底图对比的灰阶前景；文字 + 背景模式先选择与底图对比的背板，再选择与背板对比的文字。
- 高标准差区域增加 0.10 背板 alpha，上限 0.92。
- 透明源图先合成到白色后取样，获得可预测的安全回退。
- CoreText 使用 `kCTForegroundColorFromContextAttributeName`，允许每个平铺实例使用不同颜色而不重建文字布局。

## 剪贴板状态机

- `NSPasteboard` 没有稳定的变更通知，应用在主窗口可见时每 0.75 秒读取 `changeCount`。
- 版本由 pasteboard 名称和 `changeCount` 组成，记录最后观察、最后载入和最后写入三类状态。
- 应用写入后立即记录版本，后续监听跳过该版本，阻断输出再次进入输入。
- 仅空画布模式有图片时设置待替换状态；忽略不会在相同版本再次提示。
- 打开窗口检查实际变化，切换策略时强制重新评估当前剪贴板。

## 快捷默认模板

- 默认模板 ID 改为 `@Published private(set)` 状态，并提供可测试的显式设置方法。
- 默认模板与模板库的 `lastSelectedTemplateID` 继续分开保存。
- 删除当前默认用户模板时回退到内置 `X · @wlzh`。
- 菜单每次打开时刷新默认模板名称、快捷键和勾选状态。

## 回归边界

- 自定义 Logo 的 PNG 规范化、透明通道和最长边限制保持不变。
- 当前会话的移除/恢复、模板替换、拖动定位、25%–1000% 缩放和原尺寸输出保持不变。
- 自动对比不会写回手动颜色；关闭后直接恢复保存色值。

`VERSION`、`BUILD_NUMBER`、`AppVersion`、Info.plist、README、CHANGELOG、安装说明、PRD、测试报告和 Release 文件名统一为 `0.4.0 (11)`。
