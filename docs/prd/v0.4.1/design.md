# WatermarkFlow v0.4.1 交互设计

## 操作语义

- 指针位于图片画布时，标准鼠标滚轮向上为放大，向下为缩小。
- 每次有效滚轮事件只前进一个既有缩放档位，保证结果可预测。
- 触控板双指滚动仍用于平移放大后的画布，不改变既有肌肉记忆。
- 横向滚轮输入不触发缩放，由滚动容器正常处理。
- 放大溢出后，从图片非水印区域按下并拖动可移动视图；水印是合成预览的一部分，随图片同步移动。
- 从单个水印实际边界内按下时优先进入水印定位，不启动画布平移。

## 界面反馈

- 画布底部状态持续显示“滚轮缩放”，并区分“拖图片查看”与“拖水印定位”。
- 缩放百分比菜单帮助文字说明鼠标滚轮能力。
- 画布帮助文字明确区分鼠标滚轮缩放与触控板平移。
- 既有缩放百分比实时更新，无需新增控件或弹窗。

## 边界

- 功能仅在主窗口画布区域生效，不拦截侧栏、菜单或其他应用的滚动。
- 空画布不执行缩放。
- 到达 25% 或 1000% 后保持当前比例。
