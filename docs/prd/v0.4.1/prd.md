# WatermarkFlow v0.4.1 产品需求

## 背景

现有画布可通过按钮、百分比菜单和快捷键缩放，但使用鼠标检查大图时需要反复移动指针点击。应允许指针位于画布内时直接使用标准鼠标滚轮缩放，同时保留触控板平移能力。

## 目标

- 标准鼠标滚轮在画布范围内可逐级放大或缩小图片。
- 缩放继续使用既有 25%、50%、75%、100%、125%、150%、200%、300%、400%、600%、800%、1000% 档位。
- 向上滚动放大，向下滚动缩小，并尊重 macOS 的滚动方向设置。
- 精细触控板滚动和横向滚动继续交给画布，用于查看放大后的其他区域。
- 图片超出显示区域后，可按住图片非水印区域拖动查看；图片和水印作为整体移动，模板中的水印坐标不变。
- 从单个水印本体开始拖动时仍调整水印位置，不与画布平移混淆。
- 缩放只影响编辑预览，不改变原图像素、水印参数、输出尺寸或模板持久化数据。

## 验收标准

- 有图片时，画布内垂直鼠标滚轮可切换到相邻缩放档位。
- 25% 和 1000% 时继续向外滚动不会越界。
- 空画布滚轮操作不改变状态。
- 精细滚动设备和以横向为主的滚动事件不会触发缩放。
- 画布外滚轮事件不被拦截。
- 放大溢出时，从图片非水印区域拖动可平移至受约束的可视范围；未溢出时不启动平移。
- 平移前后模板水印位置完全一致，水印在屏幕上随图片同步移动。
- 现有按钮、百分比、快捷键、画布平移、水印拖动、复制和导出功能保持不变。
