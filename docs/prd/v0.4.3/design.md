# WatermarkFlow v0.4.3 交互设计

## 快捷处理

1. 用户复制图片并按下快捷键。
2. 菜单栏图标显示沙漏，表示正在读取或处理。
3. 原生图片立即进入渲染；HTML 单图从原 HTTPS 地址读取后进入相同渲染流程。
4. 成功时显示勾选并播放完成提示音，剪贴板替换为带水印 PNG。
5. 失败时显示警告图标、播放提示音并打开编辑器展示具体原因。

## 重复操作

- 上一个快捷任务尚未结束时，后续快捷键不启动重复下载或重复渲染。
- 每次状态图标只由最新状态恢复为品牌图标，避免沙漏与成功状态互相覆盖。

## 菜单栏模板

- “选择模板快速生成并复制”用于临时选择模板并立即处理一次。
- “设置快捷默认模板”只更新快捷键默认项，当前模板显示勾选标记。
- “使用快捷默认模板：模板名 · 快捷键”使用已经选定的默认项立即处理。
- 用户模板新增、删除或改名后，两个模板子菜单均在打开时动态重建。

## 隐私说明

- “关于”窗口说明调整为“图片仅在本机处理；网页图片仅从原地址读取”。
- 后台剪贴板自动发现不读取远程图片。
- 主动网页回退只接受 HTTPS 单图，不上传图片或合成结果。
