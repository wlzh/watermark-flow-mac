# WatermarkFlow v0.4.5 产品需求

## 背景

默认快捷键 `⌥⌘W` 同时是 macOS 标准的“关闭当前应用全部窗口”命令。微信及其他前台应用可能优先响应自己的标准菜单命令，导致用户复制了有效图片后按快捷键没有生成水印。现场图片文件 URL、文件可读性和水印模板均正常，问题发生在快捷键事件到达快速处理之前。

## 目标

- 默认快捷键不得与 macOS 标准菜单命令冲突。
- 旧版本保存的默认快捷键应自动迁移，不要求用户手动重设。
- 用户自行录制的其他快捷键必须保持不变。
- 恢复默认按钮、菜单栏提示、文档和实际注册值必须一致。
- 不修改模板、图片、色值、默认模板或剪贴板策略。

## 验收标准

- 新安装或没有保存快捷键时默认使用 `⌃⌥⌘W`。
- 保存值恰好为旧默认 `⌥⌘W` 时，启动后迁移并持久化为 `⌃⌥⌘W`。
- 自定义快捷键跨重启保持原值。
- 复制原生图片、本地图片文件或 HTML 单图后，新快捷键继续使用快捷默认模板生成并复制。
- 33 个核心测试、应用自检、Universal 构建、本机安装和真实键盘验证全部通过。
