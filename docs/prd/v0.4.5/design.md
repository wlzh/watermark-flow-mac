# WatermarkFlow v0.4.5 交互设计

## 默认快捷键

- 主窗口录制框、恢复默认按钮、菜单栏命令和工具提示统一显示 `⌃⌥⌘W`。
- 用户仍可点击录制框并按下其他包含 Command、Option 或 Control 的组合键。
- 迁移在启动时自动完成，不弹出对话框打断图片处理。

## 兼容行为

- 旧默认值只代表系统提供的历史默认，不视为用户需要长期保留的自定义设置。
- 任何不等于旧默认值的有效配置都按用户自定义处理，不迁移。
- 快捷键只决定触发方式；快捷默认模板、图片来源解析和输出逻辑保持原样。

## 失败回退

- 新组合键注册失败时保留当前有效快捷键，并在主窗口状态区显示明确错误。
- 菜单栏“使用快捷默认模板”与模板子菜单始终保留为无键盘依赖的备用入口。
