# WatermarkFlow v0.4.4 交互设计

## 来源识别

剪贴板按以下顺序解析：

1. 本地文件 URL：存在时必须恰好一个、必须是普通图片文件，并受 512 MB 上限保护。
2. 原生图片像素：直接读取 PNG、TIFF 或 AppKit 可解码的图片内容。
3. HTML 单图：仅在用户主动按快捷键、使用菜单或点击“从剪贴板载入”时尝试 HTTPS 原地址回退。

文件 URL 优先于 AppKit 的通用图片解析，因为 AppKit 会在多个图片文件中隐式读取第一个；WatermarkFlow 必须先识别并拒绝这种歧义。

## 自动载入

- “仅空画布自动载入”和“始终自动替换”都接受一个本地图片文件。
- 多文件、文件夹和非图片文件按非图片内容忽略，不弹出窗口打断用户。
- 自动载入永不解析 HTML 或访问网络。

## 主动处理

- 主窗口按钮、全局快捷键、快捷默认模板和指定模板快速处理共用同一完整解析服务。
- 单文件读取失败显示针对性错误；多文件要求用户只复制一个图片文件。
- 成功后的编辑、模板、渲染和复制行为与直接复制图片像素一致。
