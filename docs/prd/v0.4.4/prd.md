# WatermarkFlow v0.4.4 产品需求

## 背景

在 Finder 中复制图片文件时，macOS 剪贴板主要提供本地文件 URL，而不是 PNG/TIFF 像素。此前 WatermarkFlow 只把原生像素或 HTML 单图视为图片，因此复制文件后可能无法自动载入，快捷键也无法继续处理。

## 目标

- 将 Finder 等应用复制的单个本地图片文件识别为图片。
- 自动载入、主窗口手动载入、全局快捷键和菜单栏快速处理均支持该来源。
- 本地文件读取不得发起网络请求或修改源文件。
- 不得从多个文件中隐式选择一个，避免给错误图片加水印。
- 保持原有原生图片、HTML 单图、模板、位置、色值、快捷键和模板 schema 行为不变。

## 验收标准

- 剪贴板含一个可读取的本地图片文件时，载入后像素尺寸与原文件一致。
- Finder 复制图片文件后，空画布自动载入；已有画布仍遵循当前剪贴板策略。
- 按快捷键或菜单命令可直接对复制的图片文件套用选定模板并把结果写回剪贴板。
- 多个文件、文件夹、非图片文件和超过 512 MB 的图片文件不得被隐式处理。
- 多个文件在主动载入时给出“请只复制一个图片文件”的明确提示。
- 33 个核心测试、应用自检、Universal 构建、安装包、本机安装和系统文件 URL 真实流程全部通过。
