## 背景

单个角标适合标记来源，但对需要防止裁剪或二次转载的图片，用户需要把同一个水印快速重复覆盖整张图片，并控制疏密程度。

## 功能目标

- 当前模板可一键切换为“满屏”布局，或恢复“单个”布局。
- 满屏布局重复当前模板的文字、Logo、颜色、透明度、大小和旋转。
- 平铺采用隔行错位，避免形成僵硬竖列，并覆盖图片边缘。
- 密度提供 1–10 个离散等级，数值越大间距越小、覆盖越多。
- 布局模式和密度随每个模板自动保存，菜单栏快速生成同样生效。
- 旧版模板无损迁移，默认继续显示单个水印。

## 交互规则

1. “排版”区增加“单个 / 满屏”分段选择，一次点击切换。
2. 仅满屏模式显示“平铺密度”滑杆和当前等级。
3. 满屏模式隐藏快速位置，且画布拖动不改变单水印位置。
4. 切回单个模式时恢复该模板上次保存的位置。
5. 移除、恢复、缩放、复制、导出、默认模板和快捷处理沿用现有行为。

## 非目标

- 不在本版本加入多个不同水印图层。
- 不提供每一枚平铺水印的单独编辑。
- 不把平铺结果写回原始图片；编辑仍为当前会话非破坏式。

## 验收标准

1. 文字、X、YouTube 和自定义 Logo 模板均可满屏平铺。
2. 1 级与 10 级输出存在可量化覆盖差异，10 级覆盖像素更多。
3. 横图、竖图、小图与 4K 图片保持原始输出尺寸。
4. 模板重启后恢复布局和密度，旧 schema 1 模板自动迁移为 schema 2。
5. 完整测试、Universal 构建、签名、本机安装、界面复验和 Release 校验通过。
