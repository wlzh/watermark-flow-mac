# WatermarkFlow v0.3.0 设计

## 数据模型

`WatermarkTemplate` 增加：

- `layoutMode`：`single` 或 `tiled`，默认 `single`。
- `tileDensity`：范围 1–10，默认 5。

模板库 schema 从 1 升级为 2。自定义解码对缺失字段提供默认值，因此 v0.2.x 和更早模板不会加载失败；保存时写回 schema 2。

## 平铺算法

渲染器先计算一次水印徽章的字体、图标和尺寸，然后复用该布局逐枚绘制。密度 1–10 映射为从 2.9 到 1.4 的间距倍数；奇数行水平偏移半个步长形成错列网格。网格从画布外一格开始到画布外一格结束，使旋转后的水印仍能覆盖边缘。

徽章高度继续由 `relativeHeight` 决定，所以同一模板在不同分辨率下保持相近视觉比例。透明度、旋转、颜色和 Logo 渲染与单水印共享同一绘制函数。

## 交互与兼容

满屏模式忽略并隐藏位置控制，但不清除 `position`。切回单个即可恢复原位置。模板自动保存、默认模板、菜单栏快速处理、无水印状态和全分辨率输出无需新分支。

## 性能边界

字体排版只计算一次，循环内不重复构建 `CTLine`。平铺数量由徽章尺寸和画布比例决定；预览继续遵守 1200–6000 像素自适应上限，输出才使用原始分辨率。
