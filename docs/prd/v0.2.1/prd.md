## 目标

对 `v0.2.0` 全链路发布结果进行独立复核，修正空画布菜单便利性和超大自定义 Logo 对模板存储、自动保存及预览造成的性能风险，并增加版本联动门禁。

## 需求

1. 空画布时，主菜单的导出、生成和清空必须禁用，而不是点击后才报错。
2. “从剪贴板载入”提供 `⇧⌘V` 快捷键。
3. 自定义 Logo 最长边不得超过 1024 像素，缩放必须保持宽高比和透明通道；小 Logo 不放大。
4. 每个模板继续独立保存文字、Logo、三类颜色、透明度、大小、旋转和最后拖动位置。
5. 发布门禁必须校验源码版本、构建号、App 元数据、README、PRD、测试报告和双架构产物一致。

## 验收标准

- 空画布菜单的三项命令通过 AppKit 验证为禁用。
- 4096×2048 Logo 规范化为 1024×512，PNG 仍包含 Alpha。
- 128×64 Logo 保持原尺寸。
- 竖图与 64×64 小图输出尺寸不变。
- 核心测试、应用自检、Universal 构建、本机安装、深浅色界面和远程 Release 校验全部通过。

## 非目标

- 本次不增加批处理和 Finder Quick Action。
- 不改变“原图仅在当前进程会话内保留”的边界。
- Developer ID 签名与 notarization 仍需 Apple 开发者证书。
