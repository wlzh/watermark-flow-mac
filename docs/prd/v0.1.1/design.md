# WatermarkFlow v0.1.1 交互设计

## 自动保存反馈

编辑器标题区保留当前状态提示。参数发生变化后延迟约 250 ms 自动保存，成功后状态显示“模板设置已自动保存”；连续拖动或滑块操作只在停止变化后落盘，避免界面卡顿。

## 恢复规则

- 启动时恢复最后选中的模板和该模板最后保存的参数。
- 导入新图片只替换原图，不改变模板、位置或颜色。
- 切换模板前保存正在编辑的模板，再载入目标模板的保存值。
- “设为默认”决定全局快捷键模板，不改变编辑器的最后选择语义。

## 内置模板

内置模板与用户模板采用相同编辑体验。内置模板删除按钮保持禁用；代码中的原始值作为缺失或损坏存储时的安全回退。
