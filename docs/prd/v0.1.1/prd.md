# WatermarkFlow v0.1.1 产品需求文档

## 文档信息

- 版本：`v0.1.1`
- 状态：已完成
- 日期：2026-09-06

## 目标

用户对水印模板的每一次有效修改都应成为下一次处理的默认状态，避免重启应用或导入新图片后重复设置。

## 功能需求

- 自动保存文字、品牌类型、自定义 Logo、文字色、背景色、图标色、透明度、相对大小、归一化位置和旋转角度。
- 内置模板允许修改并持久化，但不允许删除。
- 用户另存的模板继续持久化并允许删除。
- 记录最后选中的模板，重启后自动恢复该模板及其全部设置。
- 导入下一张图片时不重置当前模板参数。
- 设置快捷处理默认模板时，先保存当前编辑值，确保 `⌥⌘W` 使用最新参数。
- 应用退出前强制保存尚未完成延迟写入的修改。
- 自动迁移 `v0.1.0` 的模板数组文件，不丢失用户模板。

## 边界

- 继续不保存原图、输出图片和编辑历史。
- 不提供跨设备同步。
- 不自动修改模板名称；另存模板时由用户命名。

## 验收标准

- 修改内置模板任意参数后，重新创建存储实例得到相同值。
- 用户模板和自定义 Logo 二进制数据往返一致。
- 最后选中的模板 ID 重启后恢复。
- 旧版 JSON 数组成功迁移到新版模板库结构。
- 零距离单击不会触发无意义的参数变化或位置写入。
