## 目标

在不改变“第一版仅保证当前编辑会话内无损编辑”的前提下，提高多模板快速处理、会话清理、暗色可读性、大图交互性能和公开分发完整度。

## 功能需求

1. 菜单栏展示所有已保存模板，用户选择后直接处理剪贴板图片并复制结果；默认模板带勾选。
2. 全局快捷键使用默认模板，允许录制新组合键、即时注册、自动保存和恢复默认 `⌥⌘W`。
3. 画布右键和底部按钮均可清空当前原图与预览水印；清空不得删除模板、色值、Logo、位置或其他持久设置。
4. 深色和浅色模式分别使用语义色板，正文避免纯白高亮，按钮、选择器、输入框、分隔线和状态色保持一致层级。
5. 大图交互预览最长边不超过 1200 像素，复制与导出必须保持原图像素尺寸。
6. 生成 Universal macOS Release 压缩包和 SHA-256 校验文件。

## 验收标准

- 三个内置模板及用户模板均出现在快捷子菜单，选择任意项可生成对应水印。
- 模板修改后无需另存，快捷处理读取已保存的最新值。
- 每个模板分别保存最后一次拖动位置；左下、中间等位置在下一张不同比例图片上按相对坐标恢复。
- 快捷键修改后立即生效，重启后恢复；冲突时不覆盖有效旧配置。
- 清空后图片和画布水印消失，模板数量与设置不变。
- 深浅模式不存在浅底白字或大面积纯白眩光。
- 4000 × 3000 输入的预览为 1200 × 900，最终输出仍为 4000 × 3000。
- 构建产物同时包含 `arm64` 和 `x86_64`，版本、作者与链接元数据一致。

## 非目标

- 不保存或恢复跨进程的原图编辑工程。
- 不提供批处理、Finder Quick Action、云同步或在线上传。
- 本版本不承诺 Developer ID 签名和 Apple notarization。
