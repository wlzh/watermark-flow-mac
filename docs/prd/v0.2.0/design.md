# WatermarkFlow v0.2.0 设计

## 交互结构

- 菜单栏“选择模板快速生成并复制”是动态子菜单，打开时从当前模板库重建，默认模板显示勾选。
- “使用默认模板”与全局快捷键保持最短路径；快捷键文本随配置同步更新。
- 清空入口同时放在画布右键菜单和底部工具栏。其对象是会话图像状态，而非模板库。
- 快捷键录制控件点击后进入录制态；`Esc` 取消，缺少 `⌘`、`⌥`、`⌃` 的组合被拒绝。

## 视觉系统

界面使用背景、表面、控件填充、主文字、次文字、边框、强调色、强调色前景和画布九类语义色。深色主文字为暖灰 `#E5E0D4`，避免纯白大面积发光；浅色保持纸张质感。原图画布在两种模式下均维持低亮中性背景，突出内容而非控件。

## 渲染与性能

源图始终保存在内存中。编辑变化仅生成最长边 1200 像素的预览，位置、字号和 Logo 按归一化参数同比缩放。复制或导出时从源图和当前模板重新全分辨率绘制，避免预览降采样污染成品。

编辑窗口明确禁用 macOS 窗口状态恢复，进程重启后不还原上次画布快照。

## 持久化

模板库继续使用版本化 JSON。快捷键使用 `UserDefaults` 中的 Codable 数据，保存 Carbon key code、modifier flags 和显示字符。会话图片不写磁盘。

水印位置以 `0...1` 的图片归一化坐标保存在各自模板中。拖动结束立即落盘，因此模板在后续图片上保持相同的相对位置，不依赖上一张图片的像素尺寸。
