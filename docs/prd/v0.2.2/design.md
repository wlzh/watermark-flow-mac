# WatermarkFlow v0.2.2 设计

## 状态模型

`EditorViewModel.isWatermarkEnabled` 表示当前编辑会话是否启用唯一水印叠加层。该值不写入模板库；载入新图片或清空会话时恢复为 `true`。模板内容仍按原有机制自动保存。

## 交互规则

- 水印显示时，操作名称为“移除当前水印”。
- 水印隐藏时，操作名称为“添加所选模板水印”。
- 选择任何模板都会把状态切回显示，并从原图重新渲染该模板，因此属于替换而非叠加。
- 水印隐藏时禁止拖动位置，但允许提前编辑模板参数。
- “清空画布”仍同时移除当前图片和会话叠加状态，且不删除模板。

## 渲染路径

`WatermarkRenderer` 提供带水印与 source-only 两组全尺寸和预览方法。两条路径均从保留的 `sourceImage` 创建新位图；全尺寸输出保持原图像素，预览在 100% 时最长边为 1200 像素，并随放大比例按需提高。

## 画布缩放

100% 定义为适合当前画布窗口。放大后，图片容器按比例增大并由双向 `ScrollView` 提供滚动访问；水印拖动的位移除以缩放后的画布尺寸，所以保存的归一化位置保持稳定。预览像素随缩放按需提高，最长边上限为 6000 像素，避免超大原图造成无界内存占用。缩放范围为 25% 至 1000%，状态只属于当前画布，新载入图片恢复 100%。

## 边界

本版本的删除只针对应用在当前会话中管理的叠加层。若导入的图片像素本身已有水印，该内容属于原图，无法通过此操作移除。
