## 背景

`v0.3.0` 增加单个与满屏布局，但两种布局共用颜色、透明度、大小和旋转。一种布局的调节会覆盖另一种布局的效果，不符合两种使用场景分别调优并重复使用的需求。

## 功能目标

- 每个模板分别保存“单个样式”和“满屏样式”。
- 两套样式各自包含文字色、背景色、图标色、透明度、大小和旋转。
- 单个模式独立保存归一化位置，满屏模式独立保存 1–10 级密度。
- 品牌、文字、自定义 Logo 和模板名称继续共享，避免维护两个内容副本。
- 布局切换、应用重启、下一张图片、默认模板和菜单栏快速处理均恢复并使用对应配置。
- 已有 `v0.3.0` 及更早模板无损迁移，不改变升级后的初始视觉效果。

## 交互规则

1. 用户先选择“单个”或“满屏”，界面随后显示当前布局名称和对应的样式参数。
2. 调整颜色、透明度、大小或旋转只修改当前布局的配置。
3. 切换布局立即显示目标布局上次保存的参数，不复制也不覆盖另一套值。
4. 单个模式显示位置工具并允许拖动；满屏模式显示密度工具并忽略拖动。
5. 修改继续自动写入当前模板，快速生成读取已保存的活动布局及其配置。

## 非目标

- 不增加多个独立水印图层。
- 不允许逐枚编辑满屏水印。
- 不把编辑结果写回原图，仍保证当前会话内非破坏式编辑。

## 验收标准

1. 同一模板可保存两套明显不同的视觉参数，来回切换不串值。
2. 重启应用后两套配置、单个位置、满屏密度和最后布局均完整恢复。
3. 渲染器只读取当前布局的视觉配置，非活动配置变化不影响输出。
4. schema 1、schema 2 数据均迁移到 schema 3，升级后模板内容和当前外观不丢失。
5. 核心测试、应用自检、Universal 构建、签名、本机安装和 Release 资产校验通过。
