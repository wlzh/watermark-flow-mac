# WatermarkFlow v0.1.0 产品需求文档

## 文档信息

- 版本：`v0.1.0`
- 状态：已完成
- 日期：2026-09-06
- 目标平台：macOS 13+
- 作者：X @wlzh
- 网站：https://869hr.uk

## 背景与目标

用户经常需要在转发图片前添加固定来源标识。现有通用图片编辑器操作链过长，本产品需要把“复制图片、套用水印、复制结果”压缩为一次快捷操作，同时保留临时精细调整能力。

成功标准：常用模板快速路径不超过一次快捷键；编辑路径可在一个窗口完成；处理结果能直接粘贴到其他 macOS 应用；关闭会话后不残留原始图片工程。

## 功能范围

### P0 图片输入

- 用户可从系统剪贴板读取图片。
- 用户可将图片文件拖入编辑区域。
- 用户可通过文件选择器打开图片。
- 无有效图片时，不允许生成空输出，并展示明确状态。

### P0 水印编辑

- 支持文字、X、YouTube 和用户选择的 Logo。
- 支持修改文字、前景色、背景色、图标色、透明度、相对大小和旋转角度。
- 支持在预览区域拖动水印位置。
- 原图与水印参数在当前编辑会话内保持分离。

### P0 默认模板

- `X · @wlzh`：X 标识和用户名 `@wlzh`。
- `X · @gxjdian`：X 标识和用户名 `@gxjdian`。
- `YouTube · 短裤AI分享`：YouTube 标识和文字 `短裤AI分享`。
- 三套内置模板始终可恢复，不因用户删除操作丢失。

### P0 生成与输出

- “生成并复制”将当前原图与水印合成为扁平图片并写入系统剪贴板。
- 输出保持原图像素尺寸。
- 支持导出 PNG 和 JPEG。
- 快捷键 `⌥⌘W`直接使用默认模板处理剪贴板图片并把结果写回剪贴板。

### P1 模板管理

- 当前参数可另存为用户模板。
- 用户模板跨应用启动持久保存。
- 任意模板可设为快速处理默认模板。
- 用户模板可删除，内置模板不可删除。

## 明确不做

- 不保存包含原图的工程文件。
- 不恢复已经导出的扁平图片图层。
- 不提供批量处理、云同步、账号系统、OCR 或在线素材库。
- 不在 `v0.1.0` 提供 App Store、Developer ID 签名或 notarization。

## 验收标准

- 三个内置模板的品牌、文字和默认颜色正确。
- 导入任意尺寸位图后，预览和输出比例正确，输出像素尺寸不变。
- 修改所有可编辑参数后，合成结果同步变化。
- 水印位置始终被限制在图片归一化坐标范围内。
- 复制输出可从系统剪贴板重新读取为图片。
- 用户模板保存后重新加载内容一致。
- Release `.app` 可安装并启动，菜单栏入口和全局快捷键可用。

## 非功能要求

- 图片仅在本机内存和用户主动选择的输出路径中处理，不上传网络。
- 核心渲染和模板存储必须可自动化测试。
- 文档、版本、构建产物元数据与 Git 标签保持一致。
