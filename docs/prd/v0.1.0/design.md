# WatermarkFlow v0.1.0 交互设计

## 视觉方向

界面采用温暖纸张底色、深墨色文字和蓝绿色强调色，突出工具感而不是通用灰色表单。标题使用 Avenir Next，正文使用系统中文字体回退。预览区使用深色画布，使浅色和透明水印边界清晰。

## 编辑器布局

```text
┌──────────────────────────────────────────────────────────────┐
│ WatermarkFlow                         状态 / 原图像素尺寸     │
├───────────────────────────────────┬──────────────────────────┤
│                                   │ 模板选择                 │
│                                   │ 品牌与文字               │
```

## 关键流程

### 快速路径

复制原图 → 按 `⌥⌘W` → 默认模板合成 → 结果覆盖剪贴板 → 直接粘贴。

### 编辑路径

打开编辑器 → 剪贴板/拖放/文件导入 → 选择模板 → 拖动水印并调整参数 → 生成并复制或导出。

### 模板路径

调整当前水印 → “另存为模板” → 输入名称 → 保存；“设为默认”决定全局快捷键使用的模板。

### 拖动规则

鼠标按下时记录水印起始位置，超过 3 pt 的移动阈值后才开始拖动，并按鼠标位移增量更新归一化坐标。单击不改变水印位置，连续重绘不会重新捕获鼠标绝对坐标。纯图片、纯文字和 Logo+文字组合均作为一个水印图层整体移动。

### 关于窗口

使用独立的固定尺寸窗口展示应用图标、名称、版本、作者、可点击网站和本地处理说明，不复用系统多行 credits 面板。

## 状态反馈

- 无图：画布显示导入引导，生成按钮禁用。
- 成功复制：状态栏显示结果像素尺寸和成功信息。
- 输入无图片：窗口置前并显示错误状态，不破坏当前编辑图。
- 导出完成：显示文件名；取消导出不改变状态。

## 尺寸与可访问性

- 默认窗口 `1080 × 720`，最小窗口 `900 × 620`。
- 主要点击目标高度不低于 32 pt。
- 颜色并非唯一状态信号，所有结果同时提供文字说明。
- 控件使用明确标签并支持键盘焦点。
