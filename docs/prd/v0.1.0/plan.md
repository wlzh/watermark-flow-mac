# WatermarkFlow v0.1.0 开发计划

## 里程碑

| 阶段 | 内容 | 状态 |
|---|---|---|
| M1 | 需求收敛、版本文档、工程初始化 | 已完成 |
| M2 | 核心模型、默认模板、渲染与存储 | 已完成 |
| M3 | 菜单栏、编辑器、拖放、快捷键与导出 | 已完成 |
| M4 | 单元测试、剪贴板自检、构建安装 | 已完成 |
| M5 | 本机验收、Git 提交、GitHub 推送 | 已完成 |

## 任务与责任

- Codex：需求文档、设计、开发、测试、构建、安装、版本记录和仓库初始化。
- 用户：提供固定模板身份信息，并在后续迭代反馈实际转发体验。

## 发布门禁

- `swift run WatermarkFlowTests` 全部通过。
- Release 构建成功。
- 三个内置模板自检通过。
- PNG 渲染保留原图像素尺寸。
- 模板 JSON 保存和加载往返一致。
- 系统剪贴板写入后可重新读取。
- `.app` Info.plist 版本为 `0.1.0` 且 codesign 校验通过。
- 安装后的主进程可启动并保持运行。
- Git 工作树干净，远程默认分支与本地提交一致。

- `v0.3.0`：工程文件、模板导入导出、iCloud 同步。
