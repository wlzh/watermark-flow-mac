# WatermarkFlow 0.4.0

本版本完善多模板快捷使用、剪贴板自动载入和复杂图片上的水印可读性，同时保持旧模板默认效果不变。

## 变化

- 右侧可直接选择“快捷默认模板”，菜单栏快速命令会显示实际模板名称。
- 主窗口可自动发现新复制图片，支持关闭、仅空画布自动载入和始终自动替换。
- 默认不会覆盖已有画布，而是显示“载入并替换”或“忽略”。
- 应用自己的生成结果不会被再次自动载入，避免重复叠加水印。
- 单个与满屏样式分别保存自动对比模式和强度。
- 自动对比按水印实际区域取样，满屏时每个水印独立适配。
- 可选择仅适配文字或同时适配文字与背景，并使用柔和、标准、强烈三档。
- 自定义 Logo 与 YouTube 品牌色保持原色，关闭自动对比即可恢复手动色值。

## 兼容性

模板存储升级为 schema 4。旧模板自动迁移，单个和满屏自动对比均默认关闭，不改变原有文字、Logo、颜色、位置、密度或渲染效果。

## 安装提示

当前二进制为 Universal `arm64 + x86_64`、MIT License、ad-hoc 签名且尚未 notarize。首次启动若被 Gatekeeper 拦截，请在 Finder 中按住 Control 点击应用并选择“打开”。
