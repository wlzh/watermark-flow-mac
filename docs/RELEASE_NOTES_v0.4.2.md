# WatermarkFlow v0.4.2

本版本重新设计 WatermarkFlow 的产品图标，使它更直接表达图片水印能力。

## 主要变化

- App 图标改为图片卡片上叠加 W 水印带，并保留现有青绿、暖白和金色品牌配色。
- 菜单栏改用“图片框 + W 水印徽标”单色模板图标，可自动适配深浅菜单栏。
- About 窗口直接显示实际 App 图标，不再使用旧印章图形。
- 快速生成完成时使用通用勾选反馈，避免旧印章短暂出现。
- 补齐图标资源、自检和版本化文档门禁。

## 兼容性与数据

- 模板 schema 保持 4，不迁移或改写已有模板、颜色、位置或快捷设置。
- 图片处理、输出、剪贴板、快捷键和全部模板功能保持不变。
- 支持 macOS 13 及以上的 Apple Silicon 与 Intel Mac。

## 安装提示

当前安装包为 ad-hoc 签名且未经过 Apple notarization。首次打开时如被系统拦截，请在 Finder 中右键应用并选择“打开”。
