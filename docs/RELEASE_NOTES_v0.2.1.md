# WatermarkFlow v0.2.1

这是一次完整发布复核版本，重点修复空画布菜单状态和超大自定义 Logo 的性能风险。

## 变化

- 空画布时禁用导出、生成和清空菜单项。
- 剪贴板载入增加 `⇧⌘V`。
- 自定义 Logo 最长边限制为 1024 像素，保持比例和透明通道。
- 增加竖图、小图、透明 Logo、菜单状态和版本文档一致性测试。
- 引入独立构建号文件，当前版本为 `0.2.1 (5)`。

## 安装提示

当前二进制为 ad-hoc 签名且尚未 notarize。首次启动若被 Gatekeeper 拦截，请在 Finder 中按住 Control 点击应用并选择“打开”。
